# The settings page

- **Settings page** (`settings_page/`, ROADMAP #15): `python -m settings_page.server` (board-setup.sh's `lll-settings.service`, port 8080, root, its own process so a bad config can be fixed). `form.py` is the config ⇄ form logic (`apply_form` is a short list of one `_apply_<section>` helper per card, called in the order the errors are listed, each taking `(new, form, problems)` and editing `new` in place; a new field goes in its section's helper, and `tests/settings_page/test_form_pinned.py` pins every result, key order included; the Surprise characters half (`apply_surprises`, `snapshot_surprises`, `import_surprises`, the character list) lives in `surprise_form.py`, which `form.py` re-exports so callers keep importing from `form`, and which keeps the file under the 600-line cap; only shown keys change; matrix checked by `cli.matrix_problem`; the Panel card holds the Pi model (`pi_model`), the Panel size (matrix rows/cols) and `page.PANEL_SETTINGS`, each blank one naming the model's default from `form.panel_choices`, the rest under Advanced), `park_names.py` the park picker's list (ThemeParks.wiki `/v1/destinations`, refetched in the background once a day into `park_names.json` beside config.json, so the hotspot has it offline; named by `parks/names.py`, the app's own rules; a name not on it is refused on save, and with no list yet names go unchecked), `page.py` the HTML's assembly (`settings_page()` is a short list of one `<name>_card` per card, in page order, and `pin_page`; it re-exports every name the page has had, so callers and tests keep importing from `page`; the pieces: `markup.py` the document shell, top bar, notices, field/switch/section helpers and the landmark pictures (`STATIC_DIR`, `landmarks()`), `page_style.py` the stylesheet, `page_script.py` the script, and `cards/` one module per card: `live.py` (live updates, weather, Pushover), `parks.py`, `trips.py`, `sound.py`, `panel.py` (Panel and Advanced, `PANEL_SETTINGS`), `display.py`, `shows.py`, `surprises.py` (Surprise characters and Testing), `board_now.py`, `updates.py`; a new field goes in its card's module, and `tests/settings_page/test_page_snapshot.py` pins every byte of the pages' HTML against `fixtures/page/` (`PIN_REGEN=1` rewrites them on purpose; stylesheet and scripts are stored once); `server.py`'s `do_POST` runs the gates in order, then looks the path up in `PIN_POSTS` (answered to anyone) or `SIGNED_IN_POSTS`, so a new POST route is one handler and one table entry), `pins.py` the PIN gate (sessions, and Sign out ending one), `utils/pushover.py` (a re-export shim stays at `settings_page/pushover.py` for one release, for a board mid-update) the optional "Send the PIN to my phone" (ROADMAP #16: with `config.json`'s `pushover` keys, `utils/config.py:pushover_keys`; one send per `SEND_EVERY_S` whoever presses it, failed sends included; the PIN is never logged), `updates.py` the Updates card (check is a dry run in-process, listing the PRs it brings from git's merge commits; Update now and Roll back go to `systemd-run --unit=lll-update`, as an update restarts this service; Save is refused while one runs; the last outcome is `self_update`'s `outcome.json`), `server.py` stdlib HTTP. The look is the logo's storybook night (navy, indigo, gold; "LightningLane" over "LED"); its pictures are `settings_page/static/`, served at `/static/` to anyone (the sign-in page and tab show them; only `.svg`/`.png` listed there; SVG gzipped for browsers that take it, ~100 KB to ~10 KB): `icon.svg` (the castle logo, hand-kept) with `apple-touch-icon.png` and `icon-512.png` (square renders of it; re-render both if the SVG changes), and the park landmark stills plus `landmarks.json` from `tools/build_settings_art.py` (Spaceship Earth without Tink). The page never imports display code: the cards show the landmark per park chip (the script fills one in for a park added on the page), the castle under the brightness, rotation and show settings, the countdown in `utils/trips.py:countdown_message`'s own words (moved there from display/countdown for this), the characters by name, one each (`surprise_characters()`, looks grouped as on `/surprises`; no sprites), and "On the board now" from the app's heartbeat (`board_status.py`, quiet after the updater's 5-minute window). No PIN for a browser in `HOTSPOT_NETWORK` while comitup is in HOTSPOT; otherwise the PIN goes to `/run/lll-settings-pin`, which `present()` draws (`display/settings_pin.py`), and `run_frames` rechecks it every `PIN_CHECK_S` during a static hold. Save: validate, `.bak`, atomic write with the old owner/mode, `systemctl try-restart`. Its tests name the file `board-config.json`: the stub conftest fakes every `config.json` read.
